You are building Docksmith - a simplified Docker-like build and runtime system from scratch. Focus on three core concepts: build caching/content-addressing, OS-level process isolation, and image layer assembly.

CRITICAL CONSTRAINTS:
- Single CLI binary (no daemon)
- All state in ~/.docksmith/ (images/, layers/, cache/)
- NO NETWORK during build/run (pre-download base images)
- SAME isolation primitive for RUN (build) AND docksmith run
- Linux only (use VM if needed)
- No Docker/runc/containerd - implement isolation directly
- Fully offline after initial base image import

## ARCHITECTURE

**State Directory:**
~/.docksmith/
├── images/ # JSON manifests per image
├── layers/ # content-addressed tar files (sha256:digest)
└── cache/ # index mapping cache keys → layer digests

## REQUIRED INSTRUCTIONS (Docksmithfile)

1. **FROM <image:tag>** - Load base image layers
2. **COPY <src> <dest>** - Copy files (supports */** globs), creates dirs
3. **RUN <command>** - Execute shell in assembled FS → new layer  
4. **WORKDIR <path>** - Set working dir (lazy dir creation)
5. **ENV KEY=VALUE** - Image config + injected into RUN
6. **CMD ["exec","arg"]** - JSON array only, default container command

**Unrecognized instructions → immediate fail with line#**

## IMAGE FORMAT (JSON manifest)

```json
{
  "name": "myapp",
  "tag": "latest", 
  "digest": "sha256:<hash>",
  "created": "2026-01-01T00:00:00Z",
  "config": {
    "Env": ["KEY=value"],
    "Cmd": ["python", "main.py"],
    "WorkingDir": "/app"
  },
  "layers": [
    {"digest": "sha256:aaa...", "size": 2048, "createdBy": "<alpine layer 1>"},
    {"digest": "sha256:bbb...", "size": 4096, "createdBy": "COPY . /app"}
  ]
}
Manifest digest: JSON with empty digest → sha256 → insert real digest.

BUILD CACHING (CRITICAL - MUST BE CORRECT)
Cache Key (before COPY/RUN):

text
sha256(
  previous_layer_digest_or_base_manifest +
  instruction_text +
  current_WORKDIR_or_empty +
  sorted_ENV_keyvals +
  COPY_ONLY: sorted_path_sha256s
)
Cache Rules:

HIT: Reuse layer, print [CACHE HIT]

MISS: Execute→store layer, print [CACHE MISS]

Cascade: Any miss → all subsequent steps miss

--no-cache: Skip all lookups/writes

Invalidation:

COPY src change → that step + below

FROM change → all layers (via base digest)

ENV/WORKDIR change → that step + below

Missing layer → cascade miss

CONTAINER RUNTIME
Extract layers in order → temp dir

Isolate process into temp dir root

Apply image ENV + WorkingDir + CMD

Block until exit, print exit code, cleanup

Runtime flags:

docksmith run <image> [override_cmd]

-e KEY=VALUE (overrides image ENV)

CLI COMMANDS
text
docksmith build -t name:tag [context] [--no-cache]
docksmith images                 # Name Tag ID(12) Created  
docksmith rmi name:tag           # Delete manifest + OWNED layers
docksmith run name:tag [cmd] -e K=V
